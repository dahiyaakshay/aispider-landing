Crawl Pipeline

Every page goes through 10 processing stages

From URL discovery to AI scoring, every crawled page passes through a structured pipeline before results appear in the UI.

01

URL Discovery + Normalisation

Discovers internal links, external links, and resource URLs (img, script, link, video). Normalises and deduplicates via URL service - strips tracking params, hsLang, UTM, and CMS tokens.

02

HTTP Fetch + Signal Extraction

Fetches HTML with retry logic. Extracts all page signals: title, meta, h1/h2, canonical, OG tags, robots directives, hreflang, AMP, rel prev/next, cookies, HTTP version.

03

AI Signal Detection

Checks robot access for GPTBot, ClaudeBot, PerplexityBot. Detects JS dependency, llms.txt presence, author signals, publish dates, semantic HTML elements.

04

Content Processing + Chunking

Converts HTML to clean Markdown. Scores readability (Flesch). Chunks content by heading boundaries for AI retrieval analysis.

05

AI Retrievability Scoring

Computes six sub-scores: extractability, citability, structure, AI crawlability, chunk quality. Aggregated into the final AI Retrievability Score (0-100).

06

Issue Generation

Evaluates 22+ rules across 7 categories. Emits issues via SSE in real-time. Category counts, severity breakdown, affected page counts all computed correctly.

07

Post-Crawl: Redirect + Canonical Analysis

Analyses all redirect chains and canonical tags for chains, loops, and conflicts. Generates issues automatically after full crawl graph is available.

08

Post-Crawl: Duplicate + Semantic Detection

MinHash Jaccard similarity for near-duplicates. TF-IDF cosine similarity for semantic overlap and content cannibalization detection.

09

Post-Crawl: PageRank + Link Intelligence

Power-iteration PageRank on internal link graph. Generates orphan page, buried authority, and excessive outlink issues.

10

Recommendations Engine

Synthesises all post-crawl signals into prioritised site-wide and per-page recommendations. Backed by real data, not heuristics.

Technical Architecture

Production-grade. Local-first.

Built on a modern full-stack architecture. Runs entirely on your machine - no cloud, no data leaving your infrastructure.

🖥 Frontend

  • Vite 7 + React 19 + TypeScript 5.9
  • React Router v7 (file-based routing)
  • Tailwind CSS v4 + CSS variables
  • react-window virtualised URL table
  • Recharts for visualisations

⚙️ Backend

  • Node.js + Express REST API
  • SQLite via better-sqlite3 (session DB)
  • Raw SQL migrations (28 migrations)
  • Server-Sent Events for live updates
  • Axios with retry + redirect capture

🧠 Processing - Zero LLM Dependency

  • No API key required - fully algorithmic
  • MinHash Jaccard (duplicate detection)
  • TF-IDF cosine similarity (semantic)
  • Playwright for JS-rendered pages
  • Cheerio for HTML parsing

📦 Data + Export

  • 69-column CSV export
  • JSON + Markdown + llms.txt export
  • Screenshot capture + storage
  • Session-based DB per crawl
  • Sitemap generation
